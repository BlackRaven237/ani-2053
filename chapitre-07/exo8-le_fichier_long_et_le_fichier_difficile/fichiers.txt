L'écart :
Each file has it's own data and ways through which these data can be modified. So we need to remember each data
and where it can be possibly modified in order to better understand what the file promises to do. In the hard file,
we have up to 9 private members and several ways through which each member can be modified, this makes it difficult
to retain in our memory and obviously more time to understand the file. On the other hand, we have only 6 members which 
are only modified at the Constructors i.e when they are created. So we can easily understand this type of file eventhough
it is long.
