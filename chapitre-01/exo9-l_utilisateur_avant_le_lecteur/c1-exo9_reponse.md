For this exercise we are mainly focused on **`NkRef`**, what it does and what i expect it to do.

## 1. What it does
After Using `NkRef` for some minutes, I guest it's a `graphics editing tool` built essentially from `Nkentseu` similar to `MS Paint` on Microsoft Windows and i noticed the following:
 - **Drawing:** It has tools such as a pencil, a color picker, and drawboards permitting users to draw simple graphics such as shapes for instant.
 - **Themes:** It provides basic black and white modes
 - **New Options & Properties:** For now `NkRef` provides a bunch of properties and options that are common to found on other graphics editing tool such as pencil mode, gestures/move but still brings in more unique propeties such as the window opacity properties.

## 2. What I expect it to do
I expect `NkRef` in future to have more advanced features such as 

- Cropping and Resizing: Quick adjustments to screenshots or downloaded images.
- Simple Annotations: Adding text, arrows, or drawn highlights to diagrams and images.
- Basic File Conversions: Converting an image format (e.g., .png to .jpg) via Save As
